# Collection d’objets

Mode : Experience. Le visiteur explore les objets de Nicolas et ses envies.

Direction demandée : une boutique de luxe sur fond gris, avec des photographies
lisibles, un cadrage généreux, les polices du site et un accent orange discret.
Le catalogue occupe la largeur de la page. La navigation du site reste familière.

Premier écran : titre centré « Objets choisis. », introduction courte, choix
entre toute la collection, les possessions et les envies, puis objets en grille.
Les photographies occupent la majorité de chaque entrée. Pas de prix, de notes,
de panier ni de fausse disponibilité.

Interaction principale : cliquer sur un objet ouvre sa fiche. Un dialogue natif
améliore l’exploration avec JavaScript ; les détails HTML restent accessibles
sans JavaScript. Les références Amazon exactes et les alternatives sont nommées
séparément. Les envies non confirmées restent explicitement des souhaits.

Responsive : trois colonnes sur grand écran, deux sur tablette et petit mobile ;
fiche en deux panneaux sur desktop, empilée sur mobile. Les photos conservent un
support clair en thème sombre pour ne pas altérer les couleurs des produits.
