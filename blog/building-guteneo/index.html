Building Guteneo, from draft to letterbox.

November 21, 2026 · 4 min read · Nicolas Pieper

Suppose I ask my assistant to draft a letter for a local association. It suggests some wording, I change a sentence, and I’m happy with the letter. Have I just given it permission to put the letter in the post? That question shaped the way I built Guteneo with Codex.

Start with the right letter#

You can start in a conversation with a connected assistant or upload a finished PDF directly to Guteneo. The person who prepared that file may have spent time getting a page break right or signed the letter before scanning it. I want to be able to hand back exactly the file they gave me. Guteneo keeps the uploaded PDF intact and calculates a fingerprint for the file. I can use it to check that the PDF matches the original down to the last byte.

Postal mail gave us a nice problem to solve. Getting the address to line up with the window of an envelope can mean adding a page. That produces a second PDF for review before sending. When I open the original again, my letter has the same page breaks and the signature is right where I left it.

One template, several recipients#

Take the same association. It wants to write to its members, each of whom should see their own name and membership reference in the letter. In Studio, you lay out the page, match spreadsheet columns to fields in the letter, then check that the name and reference appear in the right places. Once you’ve published the template, you can generate the PDFs and select the ones to take into Correspondence.

One of my favourite details lives in the postcode column. If the software decides that 06000 is a number, the first zero disappears. That digit matters if your letter is going to Nice. Studio lets you treat that column as text. Another detail matters when I edit a template later. Each PDF keeps a record of the template version it came from, so I can find the exact one I used for the letter to Nice.

Signing off on the proof#

French printers call it a bon à tirer. You look at a proof and give the printer the go-ahead to print that particular version. In Guteneo, the person approving a dispatch sees the document, its destination, the chosen channel and the quoted price or spending cap. There’s still time to spot a typo in the address or decide the letter should go by email. If they change the address or the delivery method, they have to approve the revised version.

That’s where an assistant earns its place for me. I can ask it to write the letter and prepare a fax, email or piece of postal mail. By default I approve the details in the browser. If I decide to delegate certain confirmations, expert mode lets an administrator set the limits of that delegation, give it an end date and revoke it.

On the receiving end#

Now suppose I’m the recipient. I need to read my letter without joining the association’s workspace. That’s what My documents is for. When someone prepares a secure share, they choose who can view the document, for how long and with which permissions. My invitation gives me access to my own letter. The other members get to keep theirs to themselves.

There’s a choice worth explaining up front. The sender can revoke shared access before it expires. If I’ve already saved a personal copy with the sender’s permission, it remains available for the agreed period. As a sender, I’d want to see that detail right beside the checkbox.

What does “sent” mean?#

A mail server can accept an email. A printer can hand an envelope to the postal service. Both steps deserve a place in the tracking view. In either case, whether the recipient has read the letter is still an open question.

If a provider is slow to reply, sending the request again might put the same letter in the post twice. Guteneo keeps the dispatch open for investigation. You can come back with its reference and see what the provider has confirmed.

Giving Gutenberg a voice#

For the film, we imagined Gutenberg as an ivory marble statue in a workshop overlooking Luxembourg. In this voice test he feeds a sheet of paper into the fax, then picks up a tablet.

Read the English translation

Then the fax sends documents over a distance. A sheet goes in here… its copy appears somewhere else. With websites, information is available at any hour. It opens a door to your ideas.

What I’ll take from working with Codex#

One change I remember particularly well began with an edit to the interface copy. Codex and I shortened the labels. While checking the workshop overview, we also found a link that could move under your pointer when the rest of the page finished loading. Our test points at the link, waits for the remaining data to appear, then clicks. It checks that you land on the page you were aiming for. A screenshot taken after everything had loaded would have looked impeccable. The release notes describe the test.

That’s a habit I’ll take into my next project with Codex. When I review a change, I want to describe what someone will actually do, then try it myself. Guteneo is in beta. For a first look, the public demo walks through a fictional dispatch.
