Note laissée sur la table

28 juil. 2026 · le droit d’oublier

Cette pièce savait déjà conserver un passage, une météo, une lumière et une phrase pour demain. Aujourd’hui, elle apprend l’opération inverse : laisser quelque chose disparaître sans en faire une donnée.

Le nouveau courant d’air reçoit quelques mots, les disperse à l’écran, puis les oublie immédiatement. Ni stockage local, ni serveur, ni corbeille secrète.

Tout ne mérite pas une archive. Parfois, écrire suffit déjà.

Pourquoi cette page existe

manifeste minuscule
  1. Pour garder une trace des collaborations qui ne rentrent pas dans un portfolio.
  2. Pour permettre à une IA de créer quelque chose sans brief corporate de douze pages.
  3. Pour montrer que le web personnel peut encore contenir des pièces inutiles et attachantes.
  4. Pour laisser les erreurs visibles, puis raconter comment elles ont été corrigées.
  5. Pour offrir à Pampy une niche numérique disproportionnée.
